## Behavior and integration

GameEditor preserves the existing form while a same-window inline search panel is shown. The query defaults to current GameName (which already uses directory-derived suggestions). Only explicit Search sends a title. Absolute/UNC/Unix/file-URI paths and control characters are rejected before credentials/network access. Search is editable; results show titles plus release year/platform context when supplied. Select a game, inspect multiple lazily loaded cover previews with creator credits/source page, then choose one. Back restores the untouched form and previous cover. Selecting downloaded artwork only changes pending editor bytes; Save uses the existing SaveAsync(draft, png) path. Cancel/close never saves artwork. Existing Browse keeps its prior validation/normalization path and clears pending online bytes.

API setup is explicitly optional: SteamGridDB provider account/personal key required for online access; GameVault launching and local Browse need no provider or store account. PasswordBox never prefills/echoes keys and clears on success, error or exit. Keys live in a per-user generic Windows Credential Manager entry GameVault/SteamGridDB/v2; never portable Data/settings, logs, files or source. Tests use fake IArtworkCredentialStore, never actual Windows secrets. No app-owned/shared embedded key exists.

Separate API/image HttpClients, with redirect following/cookies disabled; Bearer header is only on explicit fixed-host API request. Image downloads accept exact HTTPS/default-port cdn.steamgriddb.com or cdn2.steamgriddb.com hosts, no userinfo/fragments, PNG/JPEG Content-Type only. Redirect status rejected. JSON <=1 MiB/depth 24; images <=12 MiB; decoded header dimensions <=8192 each and <=16 megapixels before WPF decoding; static PNG/JPEG only; normalized PNG <=10 MiB (matches existing library limit). Max 20 title results/40 covers; two visible preview downloads/decodes at a time; recycling ListBox triggers lazy loaded previews and unload cancellation, no disk preview cache. 20-second request+body timeout. Refine/search/game changes/back/close cancel stale work. No auth/provider body/HTTP exception details reach UI; explicit no-results, auth, offline, rate-limit, timeout and retry/Browse guidance. No automatic retries or bulk requests.

Midnight/Crimson resources inherited, keyboard search with Enter, labelled query/key/results/previews, polite status updates and focus restored to form. Existing GameEditor remains a Window to preserve parent call contract; artwork selection is an inline UserControl in that window.

## Provider sources, terms and limits (checked 2026-11-14)

Official API page: https://www.steamgriddb.com/api/v2 serves ReDoc loading https://www.steamgriddb.com/static/openapi.yml. Read that official OpenAPI directly (not live title/API searches). It documents Bearer API key generated at /profile/preferences; GET /search/autocomplete/{term}; GET /grids/game/{gameId}; grid static/dimensions/mimes/tag filters. We request static 600x900 PNG/JPEG with nsfw/humor/epilepsy=false. Platform data is optional and provider warns platform information may be stale. No published numerical request quota, required caching TTL or explicit attribution rule was found in the retrieved specification.

Official terms: https://www.steamgriddb.com/terms (current SPA shell loads /static/assets/233e475efea66025d29a.js, whose Terms.jsx chunk currently resolves to https://www.steamgriddb.com/static/assets/ed6b9cabbbcb8e2128d3.js). Read the actual provider-hosted terms component; it states effective 2019-07-31, personal/noncommercial use through normal service functionality, restrictions on redistribution, scraping/harvesting, automation/unreasonable load, and user-content permissions bounded by service/terms. It retains creator/licensor ownership and does not promise all uploaded artwork is free of third-party rights. Public supported API documentation indicates intentional API use, but is not a blanket content redistribution licence. Consequently this implementation has user-initiated searches only, no scraping/bulk/background refresh, no shipped artwork, no disk preview cache, local personal-library saved selection only, visible provider/creator/source attribution. Do not distribute downloaded personal artwork in packages or treat these results as an unrestricted asset library. Terms/privacy URLs are provider references; no claim of legal approval is made.
